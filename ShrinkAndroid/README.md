# Shrink

Compact Android video compressor using the phone's MediaCodec hardware through Media3 Transformer.

- 720p, 960p, 1080p, 1440p, and 4K targets
- 2.5–25 Mbps in 2.5 Mbps steps
- 24, 30, and 60 fps targets
- One-second encoded preview at any position
- HEVC hardware preferred, H.264 hardware fallback
- Output-size estimate and direct save to `Movies/Shrink`
- No source upscaling
